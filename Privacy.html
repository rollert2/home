Privacy Policy

Skedaddle Map Maker

Last Updated: January 30, 2026

1. Introduction

The Skedaddle Map Maker is a proprietary tool developed for use by Skedaddle Humane Wildlife Control employees. This Privacy Policy describes how the application handles data to assist in route planning and job site mapping. This tool is designed with a "privacy-first" approach for internal company use.

2. Information Handling and Data Collection

A. Map Data and Routes

As you use the tool to map addresses for wildlife control services, you may input:

  • Work site addresses and coordinates.
  • Custom markers and property notes.
  • Optimized route sequences.

B. Geolocation

The application may request access to your device’s GPS location to display your current position relative to work sites. This data is processed locally on your device and is not recorded or stored by the application once the session is closed.

3. Data Storage

To ensure speed and privacy, this application utilizes two specific methods of storage:

  • Local Storage: All map markers, addresses, and route data you input are stored directly in your browser's Local Storage. This data stays on your hardware and is not uploaded to a central Skedaddle database.
  • GitHub: The application’s source code and structural components are hosted via GitHub. While GitHub handles the delivery of the app to your browser, your specific job data (addresses/routes) is not stored in GitHub repositories.

4. Third-Party Services

This tool utilizes map provider APIs (such as Google Maps) to render map tiles and perform address lookups. By using this tool, you are also bound by the provider's Privacy Policy. Any address searched via the tool is sent to the map provider to return a location, but no personal employee identifiers are attached to these searches.

5. Access and Security

  • Internal Use Only: This tool is strictly for the use of Skedaddle Humane Wildlife Control employees. Unauthorized distribution of the application link or the data contained within it is prohibited.
  • No Analytics: We do not use Google Analytics, tracking pixels, or any third-party software to monitor your usage, keystrokes, or frequency of use.

6. Data Retention

Because data is stored in your browser's Local Storage, it will persist until:

  1. You manually clear your browser cache/history.
  2. You manually delete the data within the application interface.
